拾页隐私政策

更新日期：2026年10月29日｜适用版本：0.1.0

拾页是一款将网页文章保存到本地 Obsidian 仓库的 Chrome 扩展。本政策说明拾页如何处理用户数据。

1. 处理哪些信息及用途

当你主动使用拾页保存文章时，扩展会读取当前网页的网址、标题、正文及配图地址，将文章转换为 Markdown，并保留原文链接。这些内容可能包含个人信息，仅用于你请求的文章保存功能。拾页不读取整个浏览历史，不持续跟踪你访问的网站。

扩展还会处理你填写的文章名称、保存目录和仓库名称，并在你授权的目录内读写文件。为判断是否覆盖，会读取目标同名 Markdown 文件并核对原文链接。

2. 信息存储与保留

文章和下载的图片保存在你选择的本地目录，直至你自行删除；目录授权信息、仓库名称和最近保存目录保存在浏览器本地，直至被清除或卸载扩展。拾页不向开发者服务器上传上述数据，不提供云端存储。若你自行使用第三方同步服务，同步由该服务及其隐私政策管理。

3. 网络请求与数据共享

下载配图时，拾页会向对应图片服务器发送请求，服务器会接收到图片网址、IP 地址等完成请求所需的信息；图片请求不主动携带浏览器登录 Cookie。下载失败的图片会保留在线链接，阅读笔记时，阅读软件可能再次请求该图片。

除上述由你使用功能触发的请求外，拾页不向开发者或其他第三方提供文章、网址、笔记或本地目录信息，不出售数据，不用于广告、用户画像或使用情况分析。开发者不通过扩展远程访问你的笔记。

4. 你的选择与删除

你可以拒绝或撤销网站访问权限及本地目录授权，或卸载扩展以停止后续处理。可选图片权限被拒绝时，图片可保留为在线链接。卸载扩展会移除其浏览器本地设置，已保存的笔记和图片仍由你自行管理和删除。

5. 有限使用承诺

拾页对从 Chrome API 获取的信息的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。信息仅用于提供或改进用户可见的文章保存功能，不用于广告定向、出售、信用评估或贷款决策。

6. 联系与政策更新

如有隐私问题，请通过 Chrome 应用商店“拾页”详情页公布的开发者联系邮箱联系发布者。如数据处理方式发生变化，我们将更新本政策及更新日期。
